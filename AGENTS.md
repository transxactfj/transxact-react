# AGENTS.md

This repo is hand-written — unlike `transxact-node`, nothing here is generated by Fern (see `docs/adr/0001-client-only-react-sdk.md`). `@transxact/react` is client-only: it never holds a Transxact key and never calls Transxact; every call goes through the Merchant backend. Domain vocabulary is in `CONTEXT.md` (which links to the platform glossary).

Only edit files inside this repo; changes needed in the platform or other SDKs go on a follow-up list.

Anything matched by `.gitignore` must never be committed or pushed to GitHub — no `git add -f`, no un-ignoring to get a file in, no removing entries to make something committable. If an ignored file seems to belong in the repo, ask first.

## Agent skills

### Issue tracker

Issues and specs live as local markdown under `.scratch/<feature>/`; no PR triage surface. See `docs/agents/issue-tracker.md`.

### Triage labels

Default vocabulary (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`), recorded as a `Status:` line. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: root `CONTEXT.md` + `docs/adr/`. See `docs/agents/domain.md`.
